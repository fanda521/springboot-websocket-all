多实例下的同聊天室用户均可收到消息。
三、核心特性总结
跨实例消息广播：基于 Redis Pub/Sub 实现，消息可在所有服务端实例间同步；
全局 Session 映射：Redis 存储「用户 - 实例 - 会话」关系，支持跨实例消息转发；
故障自愈：自动清理无效会话映射，实例故障时不影响整体服务；
负载均衡：客户端可轮询 / 随机连接不同实例，分散压力；
超时管理：自动清理超时未发言用户，释放资源。
四、生产环境优化建议
Redis 高可用：部署 Redis 集群 / 哨兵，避免单点故障；
消息持久化：关键消息（系统通知）结合 Redis Stream 持久化；
实例监控：新增实例上下线检测、Redis 订阅状态监控；
限流熔断：对消息发送 / 订阅添加限流，防止消息风暴；
日志优化：按实例 / 聊天室维度分日志，便于问题排查；
配置中心：对接 Nacos/Apollo，动态调整超时时间、Redis 配置等。
